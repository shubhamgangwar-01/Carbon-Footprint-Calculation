# data/raw/accommodation

No separate file is stored here: the accommodation emission factors come from the
**UK DESNZ GHG Conversion Factors 2026** workbook, which covers several categories and is
stored once in `data/raw/transportation/ghg-conversion-factors-2026-flat-format-revised.xlsx`
(sheet "Factors by Category", Level 1 = "Hotel stay").
See `data/metadata/source_registry.json` and `docs/DATASET_RESEARCH_AND_ACQUISITION_REPORT.md`.
